# Brand — scireDev

**Status**: 🟡 Vote. Four directions. No application code until a mix is picked.
**Product**: a developer learning platform (courses, filters, exercises: QCM / code / graphical). Not a magazine. Not infra marketing.
**Audience**: developers who want rigor (JS before Vue, vanilla before abstraction).

---

## Keep (agreed so far)

- Name: **scireDev**. *scire* = Latin infinitive, to know / to discern. `Dev` is the audience, smaller, not a second English word.
- Ember = **a coal you tend**, not a flame, spark, or glow.
- Tree = **structure** (fork, path, curriculum), not a leafy oak, not eco-growth.
- Cards and buttons: **4–6px radius**. Not pills. Not `rounded-2xl`.
- Starting tokens we already own: ink `#262626`, minium `#F23005`, ash `#D9D9D9` / `#A6A6A6`. These can shift per concept; they are not sacred if a better plate wins.
- Copy: short, specific, developer. Kill "We're changing the way you learn to code" and "Empowering Young Developers."

## Drop

- Editorial / magazine layouts, dictionary-hero, scholarly essay pages.
- Full-dark Cloudflare cosplay, orange bloom, three icon-feature cards.
- Behance/Dribbble edtech dashboards, leafy tree logos, Viking-merch copypaste of real futhark alphabets as decoration.
- Unsplash people.

## Deepen later (after the vote)

- Exact vector of the winning mark (grid, 16px, favicon, monochrome).
- Typeface license.
- Light vs dark for the **logged-in** product shell vs the public catalog.
- Motion, OG images, exercise-engine chrome.
