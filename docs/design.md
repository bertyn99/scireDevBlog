# Brand — scireDev

**Status**: 🟡 Batch 2. One world. No application code.
**Product**: developer learning platform (courses, filters, exercises). Not a magazine.

---

## Locked

- **Catalog**: D. Stack of 4–6px slabs. Filter chips in a top slab. Course rows with title, minium underline, meta (level · hours · lessons). Quiet pattern on the right of each card.
- **Palette D**

| Role | Hex |
|---|---|
| Ink | `#262626` |
| Paper | `#F4F4F5` |
| Minium | `#F23005` |
| Slate (traces) | `#3F4A52` |
| Ash | `#A6A6A6` |

- **Pattern**: between **circuit** and **tree-rune**. Straight slate traces, pads/vias, angular forks. Not foliage. Not a copied futhark alphabet. Not a Git diamond.
- **Name**: scireDev. *scire* = to know / to discern. `Dev` smaller.
- **Radius**: 4–6px. Not pills.
